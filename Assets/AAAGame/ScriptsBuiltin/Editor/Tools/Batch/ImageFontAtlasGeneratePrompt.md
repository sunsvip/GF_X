## 硬性规则

1. 只允许在输出目录中创建文件。
2. 必须创建且只创建一张 PNG 图片，文件名必须严格等于 `[OUTPUT_FILE]`。
3. PNG 必须是透明背景，不能有纯色底、渐变底、场景背景或说明底图。
4. 图片内容只允许包含字符本身，不能添加标题、水印、示例句、UI 面板、标签、说明文字或额外装饰框。
5. 字符必须严格按照字符列表顺序排列，从左到右排成单行。
6. 图集会在 Unity 中按每个字符的横向可见范围切片，Sprite Rect 宽度允许随字符实际宽度变化。
7. 所有 Sprite Rect 必须共享完整图集高度，因此整行字符必须使用同一套垂直排版网格。
8. 每个字符必须横向独立，字符可见像素范围之间至少保留 8 像素的透明分隔列，不能互相接触、重叠或跨越到相邻字符范围。
9. 每个字符必须完整显示，并保留足够透明安全边距，描边、发光、阴影等效果也不能碰到相邻字符。
10. 主体字符基线必须一致，字符视觉大小必须统一，数学符号位于中线附近，底部标点保留在底部标点位置。
11. 字符的艺术风格、描边厚度、光影方向、透视角度和渲染质量必须统一，不能出现某个字符明显缩放、偏移或风格不一致。
12. 图集必须适合 Unity Texture2D 以 SpriteMode Multiple 作为艺术字 Sprite 图集导入。
13. 画布必须裁剪到单行字符外扩少量透明边距，禁止在右侧、下方或任意方向保留大面积空白区域。
14. 禁止修改 Unity 项目文件，禁止修改输出目录之外的任何文件。
15. 禁止生成 Markdown、JSON、PSD、预览图、汇总文件或其它额外文件。
16. 如果无法完成图片生成，必须在输出目录中写入 `failure.txt`，并说明失败原因。

生成 PNG 后立即结束，不要输出额外说明。
